# CareerFit – Skill Gap Analyzer

CareerFit is a web-based skill gap analysis platform designed to help users understand their current skills, identify skill gaps, and explore career opportunities based on their skill sets.

## Features

- **Skill Analysis:** Analyze skills and identify gaps for selected career roles.
- **Career Recommendations:** Explore career options based on required skills.
- **Career Switch Simulator:** Understand the skills needed to transition into a different career.
- **Learning Roadmap:** Get a structured roadmap to improve skills and work towards career goals.
- **Visual Insights:** View skill analysis and progress through interactive charts.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- JSON

## Project Structure

- `index.html` – Main entry page
- `css/` – Stylesheets
- `js/` – JavaScript functionality
- `data/` – JSON data files
- `pages/` – Project pages
- `dataset/` – Dataset files

## Dataset

The project uses the Indian Job Market Dataset 2025 to support role and skill-related analysis.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Explore the CareerFit features in your browser.

## Purpose

CareerFit aims to make career planning more structured by helping users understand the skills required for different job roles and identify areas where they can improve.
